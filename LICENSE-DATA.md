## What the data license covers

Everything that is a record about a system card rather than a program:

- the per-card YAML files under `sources/`
- the normalization tables under `normalization/`
- the compiled `data.json` and any other built dataset files
- prose documentation under `docs/` that describes the schema or the data

The selection, structure, normalized values, status judgments, and written
summaries in those files are the original work of the contributors to this
repository and are what the license grants rights over.

Code (everything under `scripts/`, `schema/`, `site/`, and `tests/`) is
licensed separately under the MIT License in [LICENSE](LICENSE).

## What the data license does not cover

The dataset contains short verbatim quotations from system cards, model
cards, and evaluation reports published by AI developers and third-party
evaluators. Those excerpts remain the copyright of their publishers. They
are reproduced here only to cite the source of a recorded fact, each with
the document and page it came from, under quotation and fair-use
principles. Nothing in this repository relicenses them, and this project
does not redistribute the source documents themselves.

## How to attribute

Any reasonable form that names the project and links to it satisfies the
license. For example:

> Data from the system-cards project
> (https://github.com/mdworkin21/system-cards), CC BY 4.0.

If you change the data, say so. If you build on it, you may use any
license you like for your contribution, as long as this attribution
survives.

## No warranty

The data is provided as is. Every recorded fact cites a page in a primary
document so that you can check it. Do that before relying on it.
